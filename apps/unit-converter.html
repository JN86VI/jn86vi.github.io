Unit Converter

A fast, simple and reliable unit converter and technical calculation toolbox for Android.

In DevelopmentAndroid

What it does

More than a basic converter

Unit Converter is designed to solve common conversions with as few steps as possible. Calculations that do not require external data work fully offline, no user account is required for V1.0, and one entered value can produce several useful results.

Three working modes

Classic unit conversion; multi-result conversion, where one input produces several related outputs; and technical calculators using formulas or special calculation logic.

Coverage

12 categories in the first release

The first release groups everyday and specialist functions into twelve clear categories.

Common · Engineering · Electricity · Fluids · Thermodynamics · Optics · Magnetism · Computing · Radiology · Astronomy · Sizes · Amateur radio

Everyday use

Fast access to what you actually use

Common conversions include length, mass, area, volume, speed, temperature, time and fuel consumption. V1.0 also includes Favorites, Recent items, search and configurable number formatting for fast repeat use.

Technical examples

Engineering coverage includes areas such as angle, pressure, force, torque, density and flow. Amateur-radio functions include frequency ↔ wavelength, λ fractions, dBm ↔ Watt, dBW ↔ Watt, dBm ↔ dBW and an approximate S-unit ↔ dBm reference conversion.

Planned expansion

More specialist tools after the first release

Later versions may expand the app with profiles, more advanced technical and amateur-radio calculators, and additional specialist conversion options.
